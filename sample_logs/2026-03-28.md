## 2. NRRD Structure Anomaly Discovery

### Comparison of Two Groups
| Group | Cases | Lumen (label 1) |
|-------|-------|-----------------|
| Group 1 | 001, 005, 010, 011, 012 | ~3% |
| Group 2 | 003, 008, 009, 013, 014, 015 | ~0% |

**Problem identified:** Group 2 cases have ~0% lumen after conversion!

### Root Cause
- Cases like 001: NRRD has 3 layers, all binary [0,1]
- Cases like 003: NRRD has only 2 layers, layer 0 has values [0,1,2] (non-binary!)

**Example:**
- 001: layers=3, layer0=[0,1] (binary) → correct conversion
- 003: layers=2, layer0=[0,1,2] (non-binary) → **bug**: value 2 was ignored

## 4. Enhanced convert_gt_cropped.py

### Added Features
1. **--analyze flag**: Scans all NRRD files and writes report to `gt_conversion_log.md`
2. **Adaptive merge logic**: Auto-detects binary vs non-binary layers
   - Binary (values [0,1]): uses `== 1`
   - Non-binary (values [0,1,2]): uses `> 0`
3. **Verbose output**: Shows detected patterns during conversion

### Commands

python convert_gt_cropped.py --save-nifti
