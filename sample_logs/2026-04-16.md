## 3. New Raw Cropper
- Added a new CLI tool: `convert_raw_cropped.py`
- Purpose: crop raw DICOM cine runs using Excel frame ranges and write outputs using the established sample-data naming convention
- Implemented:
  - `--input-dir`
  - `--output-dir`
  - `--excel-path`
  - `--case-start` / `--case-end`
  - `--study-col`
  - `--excel-is-1-based` / `--no-excel-is-1-based`
  - `--overwrite`
  - `--log-csv`
  - `--dry-run`
- Output format now matches historical sample data layout:
  - `<output-dir>/<case>/<case>_<VL>_cropped.dcm`
- Multi-DICOM case behavior:
  - warns and uses the first DICOM in the folder, per user preference
- Added validation for:
  - crop range bounds
  - expected saved frame count
  - missing Excel case/pullback parameters

## 4. Legacy Script Clarification
- Added a prominent note at the top of `dicom_slice_reducer_based_on_xl.py`
- The note explicitly marks it as a legacy exploratory script and directs future users to `convert_raw_cropped.py`
- This was added to avoid future confusion about which raw-data cropper should be used
